## 1. Complete Platform Guide: Overview, Layout & How to Operate Everything
**Keywords:** entire tool, whole tool, full guide, everything, what is inside, how to operate, operate this tool, guide me step by step, full platform, walkthrough, tour, how to use this tool, how this tool works, overview, architecture, all features, modules, main page
**UI_Actions:** home|🔍 Go to Search Box, area:executive|📊 Open Area 1, section:intelbase|✉️ Open Account Sentinel, section:threatgraph|🕸️ Open Threat Graph

### How It Works
**OSINT-ARSENAL & NOSTROMO** is an all-in-one Open Source Intelligence and Cyber Threat Intelligence platform built on a **Zero-Fabrication Policy** — every result comes from real network checks, curated tool databases, or configured API keys (if a third-party key is not added yet, the platform clearly marks it as unconfigured rather than inventing results):
1. **Main Landing Page (Search Home)**: Focused cleanly on the **4 Guided Workflow Cards** and the **Universal Intelligence Search Box**, which automatically detects 13 indicator types (Domain, IP, Indian/Global Phone, Email, Username, File Hash, Crypto Wallet, CVE, ASN, MAC, and Darknet Onion).
2. **Left Sidebar — Investigation Areas (Areas 1–7)**:
   - **Area 1 — Executive Briefing**: Calibrated confidence score, Risk Score, Threat Level, AI reasoning summary, public corporate records, and threat intelligence exports.
   - **Area 2 — OSINT-HUB Fanout**: Routes your target across **2,466 curated tools**, separating instant web links, Vault-unlocked tools, copyable terminal commands, and downloadable reports.
   - **Area 3 — 18-Facet Entities**: Live DNS, WHOIS/RDAP ownership, SSL certificate logs, network routing (ASNs), telecom carrier & mobile circle details, and subdomains.
   - **Area 4 — Cyber Ops & ATT&CK**: Attack-path mapping, credential-leak remediation playbooks, ready-to-use SIEM hunting queries, and defensive canary beacons.
   - **Area 5 — Breach & Darkweb**: Breach exposure summaries paired with safe clearnet darkweb directory matches.
   - **Area 6 — Deep Forensics**: Image EXIF, GPS location, and steganography studio alongside document/file hash & metadata inspection.
   - **Area 7 — DorkForge & Universal Suite**: 26 search-engine dork templates plus the 7-Typology Knowledge Graph workbench.
3. **Left Sidebar — Graphs & Topology**: **Threat Graph Map** (interactive infrastructure map) and **Knowledge Graph** (multi-entity graph with signed dossier export).
4. **Specialized Tools**: **Nexus Account Sentinel** (live email registration & data-breach scanner), **Databases (97 Sources across 15 categories)**, **MITRE Matrix**, **Passive DNS**, **Actor Attribution**, **Batch IOC Triage**, and **API Key Vault**.

### How to Operate Step-by-Step
1. **Quick Search**: On **Search Home**, enter any domain, phone number, email, IP, or username and press **Enter** (or click a **Quick Example** pill). **Area 1: Executive Briefing** opens automatically with your results.
2. **Explore Areas & Graphs**: Use **INVESTIGATION AREAS** and **GRAPHS & TOPOLOGY** in the left sidebar to switch between panels, or click any satellite node in **Threat Graph Map** to pivot to a linked target.
3. **Check Emails & Leaks**: Open **Nexus Account Sentinel** from the sidebar (or **Mode 2**) to scan an email live across GitHub, Twitter/X, Reddit, Spotify, Discord, and Have I Been Pwned.
4. **Unlock More Tools**: Click **VAULT** in the header to store your API keys (Shodan, Censys, VirusTotal, GitHub) and unlock additional tools automatically.

## 6. Nexus Account Sentinel (Email Enumeration & HIBP Breach Check)
**Keywords:** sentinel, nexus account sentinel, intelbase, email check, check email, check an email, github, twitter, reddit, spotify, discord, hibp, have i been pwned, sse, stream, risk score
**UI_Actions:** section:intelbase|✉️ Open Account Sentinel

### How It Works
**Nexus Account Sentinel** asynchronously checks whether an email address is registered on mainstream platforms and whether it has appeared in known data breaches:
- **Concurrent Platform Checks**: Runs bounded asynchronous checks across **GitHub**, **Twitter / X**, **Reddit**, **Spotify**, and **Discord** with timeout and rate-limit handling.
- **Have I Been Pwned (HIBP) Integration**: Queries HIBP v3 breach records when an HIBP API key is configured in your environment (if unset, it transparently reports that live HIBP lookup is unconfigured).
- **Real-Time Streaming**: Pushes each platform verdict and breach finding live to the dashboard as it completes.
- **Explainable Risk Score (0–100 Scale)**:
  - **Breach Severity (up to 55 points)**: +25 if passwords were compromised, +5 per breach (capped at 20), and +10 if any breach occurred within the past 2 years.
  - **Account Footprint (up to 45 points)**: +12 per high-value platform match (GitHub, Twitter/X, Discord, LinkedIn, Google, AWS, Microsoft; capped at 30), plus +5 per other registered service (capped at 15).
  - **Risk Levels**: Critical (85+), High (65–84), Medium (30–64), Low (0–29).

### How to Operate
1. Click **Nexus Account Sentinel** in the left sidebar (or **Mode 2** on the home screen).
2. Enter an email address (or click a quick preset) and click **Scan**.
3. Results stream live into the summary cards and can be filtered across **Platform Footprint Matrix**, **Breach & Leak Dossier**, **Incident Playbook**, and **Raw Evidence JSON**.

## 13. Consensus Scoring, Lookup Engine & WebCheck Jobs
**Keywords:** consensus, verdict, lookup engine, webcheck, confidence, Bayesian-shrunk, shrinkage, penalty, api key, x-api-key, rate limit
**UI_Actions:** area:executive|📊 Open Area 1, area:entities|🎯 Open Area 3

### How It Works
- **Lookup Engine**: Runs 60+ asynchronous OSINT checks across usernames, emails, phone numbers, domains, and IPs.
- **Consensus Scoring**: Calculates a **Bayesian-shrunk** confidence score (0.0 to 1.0) weighted by platform authority (major, medium, forum, niche) and module confidence, applying a reliability penalty when modules return inconclusive results or errors. Verdicts are classified as High (0.70+ with 3+ matches), Medium (0.40+), Low (1+ match), or Insufficient.
- **WebCheck Engine**: Executes 30+ parallel website checks including DNS, DNSSEC, security headers, HSTS, TLS ciphers, SSL chain, redirects, WAF detection, WHOIS, and technology stack fingerprinting.

## 15. CLI, MCP Server & Docker/Cloud Deployment
**Keywords:** cli, command line, mcp, claude, docker, docker compose, deploy, deployment, port, health, env, environment variables, render, railway, tests, pytest
**UI_Actions:** home|🔍 Back to Search Box

### How to Operate via CLI & MCP
Run commands directly with `python -m osint_arsenal`:
- `serve` — Starts the web UI and API server (honors `PORT` or `ARSENAL_PORT`).
- `modules` — Lists available lookup modules and website check jobs.
- `lookup <query>` / `webcheck <url>` / `directory -q <keyword>` / `cti <target>` — Run investigations or export HTML, JSON, CSV, or Markdown reports from the terminal.
- `mcp --transport stdio` — Exposes the toolkit over MCP to compatible AI clients.

### Deployment
- **Docker Compose**: Configure your environment variables in `.env` (including a strong JWT secret and any optional API keys) and run `docker compose up -d --build`. Persistent data and reports are stored in mounted data/report volumes.
- **Cloud PaaS (Render / Railway / Fly.io)**: Uses the included container and PaaS manifests, automatically binding to the platform-assigned port and exposing a health probe endpoint.
- **Test Suite**: Run `python -m pytest` to verify all modules.
